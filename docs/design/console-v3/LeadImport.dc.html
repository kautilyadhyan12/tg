Notes for the builder

The box sits in the middle (Boxes, way 3) because it adds people. The tick for permission and the Add button show only when somebody can be added. A warning about the file (phone numbers that need a country, and others) is a line above Your columns with a button to the exact place. When the gym's account is read-only, Choose a file and Add are switched off. On a phone the box is a full page with Add at its foot.
