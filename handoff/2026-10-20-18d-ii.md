- **Square facts for the builder (checked 2026-10-20):** the form is the Web Payments SDK from `https://sandbox.web.squarecdn.com/v1/square.js` (production `https://web.squarecdn.com/v1/square.js`); its card boxes are Square's window `single-card-element-iframe.html` (read in the script that day). Store: `card.tokenize(verificationDetails)` with `intent: 'STORE'`, `customerInitiated: true`, `sellerKeyedIn` false (true flags a mail or phone order) and a `billingContact`; Square decides whether the bank checks the buyer; `verifyBuyer` is deprecated. The token goes to CreateCard with `card.customer_id`. Card on file works in all eight Square countries (Visa, Mastercard and Amex everywhere). The console has no Content-Security-Policy today. 18d-i's scopes already cover customers and cards. Square's test area takes an `http` return only for `localhost` (see the memory note `square-sandbox-facts`); the form may need `localhost` too: check it first.
